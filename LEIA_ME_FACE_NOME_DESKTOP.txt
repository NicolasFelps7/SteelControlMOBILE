SteelControl Mobile - Facial nomeada como no Desktop
Data: 2026-09-06

O que muda em Minha Empresa > Funcionários > Cadastrar facial:
1. Primeiro aparece o campo "Nome desta facial".
2. O nome precisa ter pelo menos 2 caracteres.
3. Só depois a câmera é aberta.
4. A facial só é gravada se a validação da câmera terminar com sucesso.
5. Se cancelar o nome ou a câmera falhar, nenhuma facial é cadastrada.
6. A lista "Gerenciar facial" continua exibindo o nome salvo da facial.

Instalação:
- Extraia este ZIP na raiz do projeto SteelControl Mobile.
- Escolha substituir o arquivo existente.
- Rode:
  flutter clean
  flutter pub get
  flutter analyze
  flutter run

Este patch foi feito sobre o pacote sincronizado que já corrigiu AuthService, CompanyService, ApiClient, AppController e os fluxos faciais.
