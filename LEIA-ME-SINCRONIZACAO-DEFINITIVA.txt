STEELCONTROL MOBILE 1.11.4+23 — SINCRONIZACAO DEFINITIVA

Esta versao usa primeiro GET /maquinas/sync do Desktop.
Se a lista estiver vazia, a tela mostra Diagnostico de sincronizacao com servidor, empresa e total retornado.

IMPORTANTE: para evitar misturar patches, use preferencialmente o projeto COMPLETO.

Depois de substituir o projeto:
1. flutter clean
2. flutter pub get
3. flutter analyze
4. flutter run

Se estiver no emulador Android, o servidor normalmente deve ser http://10.0.2.2:3000.
