# IHM dedicada — Impressora 3D

Quando a máquina usa o controlador `IMPRESSORA_3D`, o Mobile substitui os cartões industriais genéricos por uma IHM exclusiva de produção aditiva.

A tela adapta os rótulos e parâmetros para FDM/FFF, SLA/MSLA/DLP, SLS e equipamentos proprietários. Ela mostra trabalho atual, progresso, camadas, tempos, temperaturas, processo, material, eixos, conexão e segurança. Campos não enviados pela impressora aparecem como `--`.

O painel é responsivo para tablet/celular e usa os mesmos dados normalizados em `dadosExtras.impressora3d` que o Desktop.
