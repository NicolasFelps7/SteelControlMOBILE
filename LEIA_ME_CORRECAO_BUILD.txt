STEELCONTROL MOBILE - SINCRONIZACAO FINAL DE ARQUIVOS
Data: 2026-09-06

Este patch corrige a mistura de versoes entre telas e servicos que causa erros como:
- faceName isn't defined
- consumeForcedLogoutNotice isn't defined
- fields isn't defined
- finalizeCompanyRegistrationFace isn't defined
- cancelPendingCompanyRegistration isn't defined

COMO APLICAR
1. Feche o flutter run atual.
2. Extraia este ZIP na RAIZ do projeto SteelControlMobile.
3. Escolha substituir/mesclar os arquivos existentes.
4. No terminal, na raiz do projeto, rode:

   flutter clean
   flutter pub get
   flutter analyze

5. Se o analyze terminar sem ERROR, rode:

   flutter run

O patch sincroniza todo o diretorio lib/ e o pubspec para manter telas, AuthService,
ApiClient, AppController, CompanyService e fluxo facial na mesma versao.
